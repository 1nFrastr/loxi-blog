Web apps often use canvas for image processing — brightness, watermarks, and so on — computing on the user’s local device.

Mini programs live inside WeChat, so they are not given much system resource. That is the first constraint.

Second, canvas code is hard to maintain: procedural APIs quickly turn into a mess.

Here is a neat solution:

> **Store images on Alibaba Cloud OSS and use OSS image processing**
>
> Append the agreed processing parameters to the URL. When parameters change, the image URL changes, and the browser loads the new image automatically.

A frontend colleague asked me about this while building real-time brightness adjustment in a WeChat mini program and hitting walls.

I suggested this approach — and got a loud “666” in return.
